ISBN Validator

International Standard Book Number — Verification Tool

Accepts: ISBN-10 (e.g. 0-306-40615-2) and ISBN-13 (e.g. 978-0-306-40615-7)
Hyphens and spaces are ignored during validation.

ISBN-10 Algorithm

Multiply each digit by its position (1–10), sum all products. Valid if sum mod 11 = 0. Last digit can be X = 10.

ISBN-13 Algorithm

Alternately multiply digits by 1 and 3, sum results. Check digit = 10 − (sum mod 10), or 0 if result is 10.
